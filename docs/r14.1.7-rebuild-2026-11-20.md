# Re-check against TDE R14.1.7 (20 November 2026)

The project was built in July 2026 against TDE R14.1.6. This is the record of rebuilding it four months
later, from a clean machine, against the release that is now on the Trinity mirror.

## Environment

| Item | Value |
| --- | --- |
| Host | Apple M4 Max, macOS |
| VM | Lima (Apple Virtualization framework), 10 vCPU, 16 GiB RAM, 40 GiB disk |
| Guest | Fedora 44 Cloud Base, aarch64, kernel 6.19.10-300.fc44 |
| Build tool | mock 6.9, chroot `fedora-44-aarch64-tde` |
| Build user | `trinity`, project at `/home/trinity/fedora-trinity-arm64` |

The original Parallels VM no longer exists, so nothing was carried over from July except this repository.

## What had changed since July

1. **The pinned sources were gone.** The mirror's `f44/trinity-r14/SRPMS/` now holds R14.1.7; every R14.1.6
   file name returns 404. Scripts 10 and 11 now name the R14.1.7 packages. `fileshareset` and `htdig` are unchanged.
2. **A new signing key.** R14.1.7 is signed with `RPM-GPG-KEY-trinity-2026`
   (fingerprint `433F 98C4 6DF3 A41D 1277 9D29 BAED FADB 0180 0978`, created 2026-07-02). With only the old key,
   `rpmkeys -K` reports `NOKEY`. Scripts 10 and 12 now fetch and import both keys.
3. **A stale version default in the specs.** The first build failed in 46 seconds:

   ```
   error: Bad file: /builddir/build/SOURCES/trinity-tqt-14.1.6.tar.gz: No such file or directory
   ```

   The R14.1.7 SRPM contains `trinity-tqt-14.1.7.tar.gz`, but the spec says
   `%if "%{?tde_version}" == ""` / `%define tde_version 14.1.6`. All twelve TDE specs in the chain do the same.
   Upstream's build farm defines the version from outside; script 12 now does too:

   ```python
   config_opts['macros']['%tde_version'] = '14.1.7'
   ```

Every other build delta from July (see the README) still applied unchanged.

## Session check

The packages were installed with `scripts/20-install-trinity-core.sh`, and a session was started by hand on
a virtual display, because the Lima VM has no screen and no login manager was set up:

```sh
Xvfb :1 -screen 0 1280x800x24 -nolisten tcp &
DISPLAY=:1 dbus-launch --exit-with-session /opt/trinity/bin/starttde
```

- KPersonalizer opened with "Welcome to Trinity R14.1.7" ([r14.1.7-welcome.png](r14.1.7-welcome.png)).
- After the wizard: `twin`, `kicker`, `kdesktop`, `ksmserver`, `klipper`, `kded`, `knotify` and `dcopserver`
